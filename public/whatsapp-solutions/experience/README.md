Generated product illustrations with fictional data, 2026-10-31.

  user-provided AitoSoftwares BotBuilder screenshot. Not an actual product capture.

  workflow, with Frutiger Aero / glassmorphism styling. Not a delivery guarantee.

Original generated PNGs remain in the local Codex generated-images directory;
project assets are self-contained WebP files. The chat alongside is a deterministic,
local-only simulator and does not use payments, AI, credentials or real recipients.
