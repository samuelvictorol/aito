# Imagens da página WhatsApp BotBuilder

Adicione nesta pasta as capturas do aplicativo com estes nomes:

- `wppbotbuilder-phone1.jpg`: tela principal no celular.
- `wppbotbuilder-phone2.jpg`: conversa ou atendimento no celular.
- `wppbotbuilder-notebook1.jpg`: painel principal no computador.
- `wppbotbuilder-notebook2.jpg`: editor de fluxos no computador.

Use capturas verticais para os celulares e horizontais para os notebooks. A página `/whatsappbotbuilder` exibe as imagens dentro das molduras; até os arquivos existirem, mostra uma apresentação provisória.
